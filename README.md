# Task API

A simple REST API built with Node.js and Express.

## Features

- Hello World API
- Express server
- Easy to extend

## Installation

Clone the repository:

```bash
git clone https://github.com/saijenivarth/task-api.git
```

Install dependencies:

```bash
npm install
```

Start the server:

```bash
node app.js
```

The server will run at:

```
http://localhost:3000
```

## API

### GET /

Returns a welcome message.

Example:

```
Hello Server
```

- Node.js
